How This Workflow Works Setup → Session → Extraction + quick links
This reference app shows a Bluebeam Studio roundtrip pattern: seed the project, upload files, launch a Session for review, then run downstream extraction to pull structured outputs back into the UI. Placeholder values are included where a live environment has not yet returned an ID or link.

Setup

  • Create or verify the target Studio Project structure.
  • Upload PDFs and seed any resources needed later.
  • Outputs typically include projectId and file references.

Session

  • Create the Studio Session used for live review in Revu.
  • Register webhook coverage and invite reviewer emails.
  • Outputs typically include sessionId and subscription metadata.

Extraction

  • Finalize the review handoff and generate a downstream artifact path.
  • Pull snapshot / structured markup outputs back into the dashboard.
  • Outputs can include downloads, markup JSON, CSV, and file metadata.
