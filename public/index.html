How This Workflow Works Setup → Session → Extraction + quick links
This reference app demonstrates the Bluebeam Studio roundtrip: seed the project, upload PDFs with an optional 5-step QC Review state model, launch a Session for live review, then run downstream extraction to pull structured markup metadata back into the dashboard. All state is written to SQLite via db.js.

Setup

  • Create or verify Studio Project folders (resources, review-documents, markup-exports).
  • Upload PDFs — optionally inject the 5-step QC Review state model via pdf-lib.
  • Outputs: projectFileId, folder IDs, customColumnsFileId.

Session

  • Create Studio Session with SessionEndDate and permission defaults.
  • Register webhook (requires public HTTPS URL).
  • Checkout files, invite reviewers. Session written to DB with polling schedule.

Extraction

  • Checkin → exportmarkups job → parse XML → DB snapshot.
  • Poller runs on schedule if pollingInterval > 0.
  • Tab 2 reads from DB — not live from Bluebeam API on every load.
